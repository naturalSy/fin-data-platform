# fin-data-platform
Oracle 기반 금융 공개데이터 수집·가공·서빙 플랫폼

## 커밋 컨벤션
`<타입>: <내용>` 형식을 쓴다.

| 타입 | 용도 |
|---|---|
| feat | 기능 추가 |
| fix | 버그 수정 |
| perf | 성능 개선 (튜닝) |
| db | 스키마 변경, 마이그레이션 |
| refactor | 동작 변경 없는 구조 개선 |
| docs | 문서 |
| test | 테스트 |
| chore | 빌드·설정 |

## 문서
- `docs/adr/` 기술 선택 기록
- `docs/api/` API 명세 초안
- `docs/tuning/` 튜닝 전·후 측정 기록
